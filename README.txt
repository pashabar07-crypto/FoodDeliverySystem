ПРОЕКТ VISUAL STUDIO
Файл решения: FoodDeliverySystem.sln
Проект: FoodDeliverySystem.vcxproj

Как открыть:
1. Запустите Visual Studio.
2. Выберите Файл -> Открыть -> Проект или решение.
3. Укажите файл FoodDeliverySystem.sln.
4. Выберите конфигурацию Debug x64 или Release x64.
5. Нажмите Ctrl+F5 для запуска без отладчика.

Как собрать и запустить без Visual Studio:
1. Запустите build.bat (автоматически найдет MSVC или g++).
2. Запустите FoodDelivery.exe или run.bat.

Тестовые учетные записи:

Основные возможности системы:
1. Гостевой режим:
   - авторизация (маскированный ввод пароля со звездами, до 3 попыток, проверка блокировки);
   - самостоятельная регистрация клиента (имя, телефон, адрес, +5.00 бонусных руб.);
   - гостевой предпросмотр меню, карточек блюд, поиска, сортировки, фильтрации и ТОП блюд.
2. Клиент:
   - каталог блюд по категориям с весом, калорийностью, рейтингом и тегами (Хит, Острое, Веган);
   - подробная карточка каждого блюда и регистронезависимый поиск (UTF-8);
   - сортировка (по названию, цене вверх/вниз, рейтингу, времени готовки);
   - фильтрация (по категории из списка, доступности, цене, тегу, калорийности);
   - корзина с изменением количества, исключением ингредиентов, настройкой приборов,
     бесконтактной доставки, комментария и чаевых курьеру;
   - промокоды (WELCOME10, STUDENT15, FREEDEL) + автоскидка 10% от 50 руб. + бесплатная доставка от 60 руб.;
   - списание бонусов и 3 способа оплаты (Наличные со сдачей, Карта, Бонусные баллы);
   - онлайн-трекер этапов доставки, отмена заказа с возвратом бонусов, оценка 1-5 звезд, повтор любого заказа;
   - личный профиль и смена пароля.
3. Курьер:
   - переключение статуса смены (На смене / Перерыв);
   - биржа свободных заказов (взятие заказа в работу);
   - карточки активных доставок (адрес, телефон клиента, комментарий, сдача/оплата);
   - обновление этапов доставки (В пути -> Доставлен) с начислением клиенту 5% кэшбэка;
   - история доставок, заработанные чаевые и рейтинг.
4. Администратор:
   - полный CRUD каталога блюд и управление стоп-листом;
   - управление заказами и этапами кухни, фильтрация/поиск/сортировка, назначение курьеров;
   - управление промокодами;
   - управление пользователями (поиск, добавление, редактирование, блокировка, удаление);
   - сводная аналитическая отчетность (выручка, средний чек, категории, ТОП блюд, курьеры).
