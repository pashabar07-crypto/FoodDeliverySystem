ПРОЕКТ VISUAL STUDIO
Файл решения: FoodDeliverySystem.sln
Проект: FoodDeliverySystem.vcxproj

Как открыть:
1. Запустите Visual Studio.
2. Выберите Файл - Открыть - Проект/Решение.
3. Укажите файл FoodDeliverySystem.sln.
4. Выберите конфигурацию Debug x64 или Release x64.
5. Нажмите Ctrl+F5 для запуска без отладчика.

Как собрать без Visual Studio:
1. Запустите build.bat.
2. После появления FoodDelivery.exe запустите run.bat.

Тестовые учетные записи:
admin / admin123
courier / courier123
courier2 / courier123
client / client123

Работа клиента:
- меню выводится одной таблицей с разделением по категориям и составом блюд;
- блюда добавляются в корзину прямо из меню (ID, количество, исключение ингредиентов);
- в корзине можно удалить позицию по номеру, очистить корзину и оплатить заказ;
- поиск по названию и категории, сортировка по названию и цене;
- фильтрация по категории, доступности и диапазону цен;
- список популярных блюд по количеству заказанных порций.

Заказы:
- адрес доставки вводится при оплате в корзине, новый адрес можно сохранить
  в профиль;
- не более 20 порций одного блюда;
- при добавлении блюда можно убрать отдельные ингредиенты
  (номера из состава), они сохраняются в заказе и чеке;
- примерное время ожидания показывается в корзине, чеке, таблице заказов
  и в сводном отчете;
- клиент может повторить последний заказ и отменить подтвержденный заказ,
  пока курьер не назначен.

Регистрация:
- Клиент регистрируется самостоятельно через пункт 2 главного меню.
- При самостоятельной регистрации адрес доставки не запрашивается.
- Курьеров и администраторов регистрирует и удаляет только администратор.
- Ввод пароля скрыт, на экране отображаются звезды.

Файлы данных создаются автоматически:
data/users.txt
data/dishes.txt
data/orders.txt
data/summary_report.txt
receipts/order_N.txt

Пароли в users.txt хранятся в зашифрованном виде.
Оплата картой является учебной симуляцией и не выполняет реальный перевод денежных средств.
